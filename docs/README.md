# Реконфигурируемые пути теплопереноса

Концепция ВКР — выпускной квалификационной работы.

Откройте [index.html](index.html) в браузере. Установка программ и запуск сервера для просмотра не нужны.

Для локального просмотра через HTTP выполните из корня проекта:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Адрес: `http://127.0.0.1:8765/docs/`.

## Размещение на GitHub Pages

1. Добавьте папку `docs` в выбранный репозиторий GitHub.
2. Откройте **Settings → Pages** (настройки → страницы).
3. Выберите **Deploy from a branch** (публикация из ветки), нужную ветку и папку `/docs`.
4. Сохраните настройки и дождитесь завершения публикации. GitHub покажет адрес сайта.

Адрес сайта: https://vldsmelov.github.io/thermal-routing-vkr/

Репозиторий: https://github.com/vldsmelov/thermal-routing-vkr

Публикуется ветка `main`, папка `/docs`.

Изображения находятся в `assets/generated/`. Они иллюстрируют принцип работы, а не результаты расчётов. Научное содержание опирается на концепцию для руководителя и описание тестовой задачи.
